CloudRig: deja IK Pole Follow = 0 en las piernas. Rigify: conserva el Local Location original del rig (no lo fuerces). La Action usa head_follow = 0, neck_follow = 0.5; para IK usa IK_FK = 0 y pole_vector = ON en upper_arm_parent.L/R y thigh_parent.L/R. El .py los configura automáticamente.

FBX CLEAN reescribe sólo la jerarquía de controles FK con compensación de rest pose. root → TORSO-Spine se conserva; FK-Spine forma la sección superior y HTP/HIP-Spine la inferior. No se reparentan los DEF ni se modifican pesos o bind matrices.

Perfil Mixamo → CloudRig basado en el preset oficial de BlendCap: Hips ROT→HIP/HTP-Spine, altura→TORSO-Spine, desplazamiento horizontal→root; además se aplica la compensación de anclaje de piernas de BlendCap y la Action original usa la jerarquía funcional de hinges/toes, sin DEF ni helpers.
